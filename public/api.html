MiniSearch API

Ranked results from our own web crawl. Plain JSON over HTTP, no key, no account. Rate limited to 60 requests per minute per IP; the headers below tell you where you stand.

Quickstart · Search · Overview · Stats · Errors

Quickstart

curl "https://minisearch.duckdns.org:6036/api/v1/search?q=how+does+bm25+work&limit=3"
fetch("/api/v1/search?q=never+gonna+give+you+up")
  .then((r) => r.json())
  .then(({ results }) => results.forEach((r) => console.log(r.rank, r.url)));

Every response is JSON and CORS is open, so you can call it straight from a browser. GET /api/v1 returns a machine-readable description of everything below.

Search

GET/api/v1/search

Ranked results for a query. Supports paging, domain filters, verticals and per-country ranking.

ParameterDefaultNotes
qrequiredThe query. A question is understood as one.
limit101–50, clamped.
offset0Skip results. Use nextOffset from the previous page.
typetexttext, image, video or short.
domain—Only this domain and its subdomains, e.g. bbc.com.
countryvisitorTwo-letter code that biases local results and language.
deeptrueMulti-pass retrieval. false is faster, slightly worse.
{
  "query": "how does bm25 work",
  "tookMs": 41,
  "total": 59,
  "limit": 3,
  "offset": 0,
  "nextOffset": 3,
  "country": "IT",
  "vertical": "text",
  "facets": [{ "domain": "en.wikipedia.org", "count": 7 }],
  "results": [{
    "rank": 1,
    "url": "https://example.org/bm25",
    "title": "BM25 explained",
    "snippet": "…BM25 ranks by term frequency…",
    "domain": "example.org",
    "score": 0.245,
    "type": "text",
    "language": "en",
    "wordCount": 812
  }]
}

Vertical results carry thumbnail, mediaUrl, provider and durationSeconds when the page publishes them. facets lists the ten domains present on this page of results.

AI overview

GET/api/v1/overview

A short answer written from the crawl, with the sources it used.

ParameterDefaultNotes
qrequiredThe question.
countryvisitorTwo-letter code.
{
  "query": "what is bm25",
  "tookMs": 1204,
  "mode": "model",
  "answer": "BM25 is a ranking function… [source](https://example.org/bm25)",
  "sources": [{ "title": "BM25 explained", "url": "https://example.org/bm25" }]
}

mode is model when the assistant wrote it and extractive when we fell back to stitching the best matching passages. Check it if you need a guaranteed-fresh answer.

Errors and limits

StatusMeaning
400Missing or unusable parameter. The body says which.
404No such endpoint — check GET /api/v1.
429Over 60 requests a minute. Wait retry-after seconds.

Rate headers on every response: x-ratelimit-limit, x-ratelimit-remaining, x-ratelimit-reset. An empty results array is a success, not an error.
